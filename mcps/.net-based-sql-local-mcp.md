# .NET SQL Local MCP Configuration
## Connection Details
- **Provider**: Microsoft.Data.SqlClient
- **Connection String**: `Server=localhost,1433;Database=TrainingDB;Trusted_Connection=True;TrustServerCertificate=True;`
- **Capabilities**:
    - `ExecuteQuery`: Run read-only SQL queries.
    - `GetSchema`: Retrieve table and column metadata.

## Integration
This MCP allows the agent to query the local training database to verify data integrity during the "Testing Loop" (Module 09).
